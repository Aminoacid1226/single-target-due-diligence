# 单一靶点调研（两阶段）· Single-Target Research

面向小分子药物研发团队的单靶点调研技能。一次使用 = 两阶段串联、两份独立报告：

1. **阶段一 · 立项调研**：判断值不值得做、打哪个适应症、走哪条路
2. **阶段二 · 竞争调研**：以阶段一结论为输入，回答谁占了什么、从哪里突围

用于：新靶点立项评估、引入资产前的独立判断、竞争格局与突围设计、年度管线复盘。
不用于：日常资讯监控、临床试验方案设计、法务与财务尽调。

## 两阶段

| | 阶段一 · 立项调研 | 阶段二 · 竞争调研 |
| --- | --- | --- |
| 回答的问题 | 值不值得做、打哪个适应症、走哪条路 | 谁占了什么、哪里还空着、怎么突围 |
| 节数 | 15 节 | 13 节 |
| 报告 | `{靶点}靶点立项调研看板_{YYYYMMDD}.html/.md` | `{靶点}竞争布局与突围策略_{YYYYMMDD}.html/.md` |
| 底表 | `_管线_`、`_专利_`、`_临床_` | `_资产_`、`_专利_`、`_学术与临床_` |
| 结束条件 | 六视角 + 六层审查通过 | 同左，且与阶段一结论一致 |

两份报告独立成文、可单独阅读；阶段二开头必须引用阶段一的核心结论与路径选择。

## 流程（十步，串联）

**阶段一 · 立项调研**

1. **界定**：靶点与别名、配体、信号方向、候选适应症、团队模态约束；列出同名混淆项与近缘受体。
2. **采集**：公司披露、临床注册、文献、专利、流行病学、市场交易六类来源并行。
3. **结构化**：建管线、专利、临床三张底表。
4. **评分**：靶点验证等级、适应症加权排序、路径加权排序。
5. **撰写**：按十五节模板成文，决策章节排在化学、药理、开发性之后。
6. **审查**：六视角分审 + 六层总审。

**交接**

7. **一致性核对**：锁定方向结论、竞争集基线、专利集与数据缺口，作为阶段二输入。

**阶段二 · 竞争调研**

8. **增量采集**：补对手临床节点、专利族、学术团队、资本事件与空白点，不重复已核验数据。
9. **机会评分与路径设计**：四维加权 + A/B/C/D 路径 + 7:2:1 资源比例。
10. **撰写与审查**：按十三节模板成文，走同一套审查；若推翻阶段一结论，回到阶段一修订。

## 评分口径

**阶段一（三套，不可混用）**

| 评分 | 主要维度 |
| --- | --- |
| 靶点验证等级 | 人类遗传学、人体药理学、动物因果、通路清晰度、疾病特异性 → T1–T4 |
| 适应症排序 | 生物学 25%、未满足 20%、市场 20%、可行性 15%、竞争 10%、监管 10% |
| 路径排序 | 科学 25%、成药性 20%、竞争 20%、IP 15%、商业 10%、执行风险 10% |

**阶段二（突围机会分）**

竞争密度 35%（逆向）、证据可行性 25%、窗口 25%、商业价值 15%。分差 <0.3 视为无实质差异；商业分最高但竞争与窗口最低的方向通常加权垫底，需在正文解释。

## HTML 格式

两阶段使用不同模板，版式规则一致：只替换 `{{…}}`，不改 CSS 与章节骨架。

- 仅两种主色：`#b8342e`、`#1a5276`；白卡片、浅灰底
- 固定结构：header → KPI 4 项 → 目录 → `section#m00`–最后一节 → footer
- 固定组件：`.item` + `.judge`、`.table-wrap` + `.table-foot`、`.warn`、`.fig`
- 禁用外部字体、CSS、JS、图片、CDN
- 定稿校验：section 数 = 目录锚点数、标签配对、无 `http(s)://` 资源引用

## 硬性规则

- 阶段顺序不可颠倒：没有立项结论，不进入竞争调研。
- 两阶段评分不混用：三套分数与机会分口径不同。
- 竞争集以阶段一为基线，阶段二只做增量，增删须注明理由。
- 结论冲突必须回改：阶段二推翻阶段一方向时，回到阶段一修订并重出两份报告。
- 安全性数据不得表述为疗效；跨种属数字不可直接比较。
- 专利结论限定在可核实范围。
- 已终止资产必须保留——它们定义安全红线。
- 估算必须列出全部假设。
- 报告不写岗位视角表述；岗位视角只用于审查流程。

## 使用

将本目录放入你的技能目录，或在对话中直接引用 `SKILL.md`。一次调用默认执行两个阶段、产出两份报告；只做立项阶段时需明确说明。

换靶点需替换七个变量：靶点与配体、适应症清单、竞争资产、专利族、已知化合物活性、评价模型与 PD 标志物、疗效门槛与监管路径。

## 使用范围

本仓库为方法论沉淀，仅含流程、模板与评分口径，不含任何在研靶点、公司管线或未公开数据；示例均为占位符。未附开源许可，保留所有权利。
