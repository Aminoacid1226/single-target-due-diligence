# 单一靶点调研 · Single-Target Due Diligence

面向小分子药物研发团队的**单靶点立项级调研**技能。一次性交付，不进入日常监控流程。

用于：新靶点立项评估、引入资产前的独立判断、年度管线复盘。
不用于：日常资讯监控、临床试验方案设计、法务与财务尽调。

| --- | --- |

| `{靶点}靶点立项调研看板_{YYYYMMDD}.md` | 与 HTML 同构的文字版 |

| `{靶点}立项调研_临床底表_{YYYYMMDD}.csv` | 注册号、期别、样本量、终点、状态、来源 |

## 七步流程

1. **界定**：靶点与别名、配体、信号方向、候选适应症、团队模态约束；列出同名混淆项与近缘受体。
2. **采集**：公司披露、临床注册、文献、专利、流行病学、市场交易六类来源并行。
3. **结构化**：建管线、专利、临床三张底表。
4. **评分**：靶点验证等级、适应症加权排序、路径加权排序。
5. **撰写**：按十五节模板成文，每节只回答一个问题。
6. **分视角审查**：药理药化、DMPK 毒理、临床注册、知识产权、商业 BD、项目管理六视角独立重读。
7. **总体审查**：逻辑、事实、口径、结构、表达、合规六层复核，通过放行清单后定稿。

## 三套评分（不可混用）

| 评分 | 回答的问题 | 主要维度 |
| --- | --- | --- |
| 靶点验证等级 | 机制是否可信 | 人类遗传学、人体药理学、动物因果、通路清晰度、疾病特异性 |
| 适应症排序 | 打哪个适应症 | 生物学匹配 25%、未满足需求 20%、市场 20%、可行性 15%、竞争 10%、监管 10% |
| 路径排序 | 走哪条路 | 科学证据 25%、可成药性 20%、竞争位置 20%、IP 15%、商业 10%、执行风险 10% |

## 十五节骨架

```
00 摘要与结论        05 临床与监管        10 交易与估值
01 生物学与验证      06 专利与 IP         11 立项决策
02 适应症地图        07 化学与 SAR        12 计划与价值
03 模态与可成药性     08 药理与转化        13 风险登记册
04 竞争格局          09 开发性与 TPP      14 方法与附录
```

顺序原则：**证据链在前、决策在中、执行与风险在后**。化学、药理、开发性必须早于决策。

## HTML 格式

复制 `assets/dashboard-template.html`，只替换占位符，不改 CSS 与章节骨架。

- 仅两种主色：`#b8342e`、`#1a5276`；白卡片、浅灰底
- 固定结构：header → KPI 4 项 → 目录 15 项 → `section#m00`–`#m14` → footer
- 固定组件：`.item` + `.judge` 结论卡、`.table-wrap` + `.table-foot` 表格、`.warn` 警示、`.fig` 内联 SVG
- 禁用外部字体、CSS、JS、图片、CDN
- 定稿校验：section 数 = 15、目录锚点 = 15、标签配对、无 `http(s)://` 资源引用

## 硬性规则

- 三套评分不可混用或并列比较。
- 安全性数据不得表述为疗效。
- 跨种属、跨实验体系的数字不可直接比较。
- 专利结论限定在可核实范围，不得写"全球无"。
- 未核实线索单列，不计入竞争集。
- 峰值销售与 rNPV 必须写明全部假设。
- 报告不写岗位视角表述；岗位视角只用于审查流程。

## 使用

将本目录放入你的技能目录，或在对话中直接引用 `SKILL.md`。换靶点时替换七个变量即可复用：靶点与配体、适应症清单、竞争资产、专利族、已知化合物活性、评价模型与 PD 标志物、疗效门槛与监管路径。

## 使用范围

本仓库为方法论沉淀，仅含流程、模板与评分口径，不含任何在研靶点、公司管线或未公开数据；示例均为占位符。未附开源许可，保留所有权利。
