# 审查协议

两级审查：先分视角，后总体。每个视角独立重读全文，只挑本视角的问题；每条问题必须落到具体章节与句子。

## 一、分视角审查（六类）

| 视角 | 必查问题 | 典型漏项 |
| --- | --- | --- |
| 药理与药化 | 活性量级是否达到候选标准？效价与偏向两条曲线是否齐全？骨架能否专利化？代谢软点是否识别？ | 工具化合物当候选；只报 IC₅₀ 不报偏向；未评估酯键、硫醚稳定性 |
| DMPK 与毒理 | 种属交叉是否支持毒理种属与模型选择？肝毒性是否有前置判据？安全窗是否量化？ | 只写"开展毒理"不写判据；把无 DLT 当安全 |
| 临床与注册 | 终点是否被监管接受？单臂数据是否被当作注册证据？患者规模与入组是否自洽？ | 终点阈值无来源；开放标签信号当疗效证明 |
| 知识产权 | 结论是否限定检索范围？FTO 是否覆盖拟做方向？优先权日与到期估算是否正确？ | "未检索到"写成"不存在"；忽略法律状态与同族 |
| 商业与 BD | 峰值假设是否逐项标注？交易锚点是否同阶段可比？定价与支付是否有依据？ | 跨阶段套倍数；市值当企业价值 |
| 项目管理 | 阶段门是否可判定？资源与工作量是否匹配？关键路径是否识别？ | 闸门写成"达到预期"等无法判定的表述 |

问题分级：**事实错误**、**口径不一**（前两级必须清零）、**表述建议**（可选）。

## 二、总体审查（六层）

| 层次 | 检查内容 | 不通过的表现 |
| --- | --- | --- |
| 逻辑 | 结论是否由证据推出；章节是否矛盾；决策是否晚于可行性证据 | 摘要结论在正文无支撑；两类排序冲突且未解释 |
| 事实 | 数字可追溯、日期一致、单位一致、指标口径一致 | 同一指标出现两个值；市值日期未标 |
| 口径 | 三套评分未混用；市场数据标级；专利结论限定范围 | 靶点级与路径级分数并列比较 |
| 结构 | 编号、目录锚点、交叉引用一致；每节只答一个问题 | 引用指向错误章节；两节同表 |
| 表达 | 无第一人称、无夸张形容词、无未定义缩写 | "显著优于""颠覆性"等无数据判断 |
| 合规 | 与日常监控隔离；无邮件动作；来源可点击；缺口已列 | 与定时任务共用文件；未标注推测数字 |

## 三、放行清单

- [ ] 章节编号、目录锚点、正文交叉引用三者一致
- [ ] 每个数字有来源，且来源可点击
- [ ] 安全性数据未被表述为疗效数据
- [ ] 跨种属、跨实验体系的数字未被直接比较
- [ ] 专利结论限定在可核实范围
- [ ] 未核实线索单列，未计入竞争集
- [ ] 评分权重与分值定义在附录可查
- [ ] 三套评分口径已区分
- [ ] 数据缺口逐条列明
- [ ] HTML 标签配对正常、无外部依赖、移动端可读
- [ ] 与日常监控任务无文件交叉
