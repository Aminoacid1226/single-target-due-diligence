# 证据与表述规则

## 一、来源分级

| 等级 | 来源 | 使用方式 |
| --- | --- | --- |
| A | 监管公告、公司原始披露（SEC/港交所/IR）、临床注册平台、同行评审原始研究 | 可直接作为结论依据 |
| B | 学会指南、系统综述、会议摘要、官方流行病学数据库 | 可作依据，需注明类型 |
| C | 二手专利索引、券商研报、媒体报道 | 仅作线索，须回溯原始来源 |
| D | 市场规模、渗透率、定价等第三方估算 | 必须标注估算并交叉核对 |

同一结论至少一条 A 或 B 级来源；只有 C 级来源的结论必须标"待核实"。

## 二、专利表述边界

- 可核验范围通常受限于可访问的检索库；结论只能写"在已检索范围内未见某类专利"。
- 每条专利须记录：公开号、申请人、优先权日、公开日、法律状态（若可得）、主题方向、核验状态。
- 未取得公开号的线索单列"待核"，不得计入竞争集或 FTO 结论。
- FTO 必须覆盖**拟做模态的全部权利类型**，抗体或肽的专利可能覆盖小分子用途。

## 三、必须排除的混淆项

- 靶点缩写与无关概念同名（缩写被平台名、项目代号或通用词复用）。
- 近缘受体的资产（同源性高但机制不同）。
- 只做间接递送、器械或诊断的报道。
- 已终止但被二手来源继续引用的项目。

## 四、七类常见错误

1. **把安全性当疗效**：无 DLT、暴露达标、PD 改变均不等于临床获益。
2. **方向混淆**：配体缺失与受体缺失的表型可能相反，模态结论须单独论证。
3. **同源受体污染**：近缘受体资产不得计入竞争集。
4. **跨种属换算**：动物效应量不能与人头对头数据并列。
5. **专利绝对化**：未检索到不等于不存在。
6. **评分口径混用**：靶点级、适应症级、路径级不可比较。
7. **结论先于证据**：决策章节必须晚于化学、药理、开发性。

## 五、数字呈现

- 每个数字后标注来源与日期；同一指标全文只用一个口径（如患者数、市值日期）。
- 估算值必须写成区间并列出全部假设，不得给单点值。
- 单位统一：金额标币种，暴露标单位，效应量标置信区间（若原文有）。
