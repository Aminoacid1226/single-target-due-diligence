# 竞争调研工作流（第二阶段，13 节）

回答的问题不是「能不能立项」，而是「谁已经占住了什么、哪里还空着、我们怎么切进去」。本阶段在立项调研通过审查后执行，以阶段一的结论为唯一输入。

## 一、在流程中的位置

| | 阶段一 · 立项调研 | 阶段二 · 竞争调研 |
| --- | --- | --- |
| 前置条件 | 无 | 阶段一通过六视角与六层审查 |
| 输入 | 靶点与适应症清单 | 阶段一的方向结论、竞争集基线、专利集、数据缺口 |
| 新增工作 | 全量采集与三套评分 | 竞争维度的增量采集与机会评分 |
| 核心产出 | 立项 / 不立项 / 条件立项 | 主攻方向、路径组合、90 天动作 |
| 报告 | 立项调研看板 | 竞争布局与突围策略 |

衔接规则：
- 竞争集以阶段一第 04 节为基线，只做增量；新增或删除资产须注明理由。
- 阶段一已核验的临床、专利、估值数据直接引用，不重复采集。
- 阶段二开头必须复述阶段一的方向结论，便于单独阅读。
- 若阶段二推翻阶段一的方向判断，回到阶段一修订并重出两份报告，不允许两份报告并存矛盾结论。

## 二、十三节骨架

| 节 | 回答的问题 | 必备内容 |
| --- | --- | --- |
| 00 结论与主张 | 竞争格局是什么、怎么突围 | 三条判断 + 一条主张 + 成立前提 |
| 01 竞争全景 | 有哪几类玩家 | 四层表：临床 / 终止 / 中国早期 / 学术 |
| 02 商业时间轴 | 谁先读出数据 | 资产甘特图 + 事件影响表 |
| 03 资本与交易 | 谁在买单 | 融资、估值、BD 结构、定价锚 |
| 04 专利布局 | 化学空间被谁占住 | 申请人 × 骨架表 + 空白判断 |
| 05 学术竞争 | 谁掌握机制解释权 | 机构 × 成果表 + 产业联动 |
| 06 机会评分 | 哪个方向最值得切 | 四维加权表 + 读法 |
| 07 空白点 | 还剩下什么位置 | 机制 / 适应症 / 模态 / 区域 / 联合 |
| 08 突围路径 | 具体怎么打 | A 主攻 / B 扩展 / C 跟随 / D 期权 + 资源比例 |
| 09 能力与资源 | 缺什么 | 能力矩阵：现状 / 缺口 / 补齐方式 |
| 10 90 天行动 | 先做什么 | 三阶段 + 每阶段停止条件 |
| 11 反制与风险 | 对手会怎么回应 | 动作 / 触发 / 影响 / 预案 |
| 12 方法与来源 | 能否复核 | 口径说明 + 来源清单 |

## 三、竞争集口径

- 只计**直接靶向该靶点**的资产；近缘受体、间接递送、器械与诊断不计入。
- 专利族与未核实线索单列，不计入临床竞争集。
- 已终止资产必须保留在表内——它们定义安全红线与失败模式，是竞争信息的一部分。
- 学术团队计入「学术」层，但只有与产业方形成合作时才计入商业竞争。

## 四、机会评分（1–5 分）

权重：竞争密度 35%、证据可行性 25%、窗口 25%、商业价值 15%；竞争密度为逆向计分。

| 维度 | 1 分 | 3 分 | 5 分 |
| --- | --- | --- | --- |
| 竞争密度（逆向） | 已有临床阶段直接竞品 | 2–3 家同阶段 | 无直接竞争 |
| 证据可行性 | 仅体外或同类失败 | 动物 PoC | 人体或强机制证据 |
| 窗口 | 对手 12 个月内读出 | 24 个月内 | 36 个月以上或无明确对手 |
| 商业价值 | 无差异、无支付方 | 有差异化主张 | 可定义新标准或替代现有疗法 |

要求：
- 分差 <0.3 视为无实质差异。
- 商业分最高但竞争与窗口最低的方向，加权后通常垫底——必须在正文解释这一反直觉结果。
- 机会分只用于排序，不替代实验判断；最大不确定性来源必须写明。

## 五、突围路径模板

| 路径 | 定位 | 必须回答 |
| --- | --- | --- |
| A 主攻 | 竞争最空、证据可达 | 首个可验证读数是什么、多久能读出 |
| B 扩展 | 同一分子的第二、第三适应症 | 信号方向是否一致、模型是否复用 |
| C 跟随 | 红海中的差异化主张 | 差异化是否可注册、是否需头对头 |
| D 期权 | 只跟踪不投入 | 触发条件是什么 |

资源比例默认 7:2:1，并在正文说明为什么不能并行。四条路同时投入通常意味着四条都停在先导阶段。

## 六、90 天行动模板

三阶段，每阶段必须有**产出**与**停止条件**。停止条件必须是可观测的（数值、模型可用性、时间），不接受「进一步评估」。

| 阶段 | 动作 | 产出 | 停止条件 |
| --- | --- | --- | --- |
| 0–30 天 | FTO、种属交叉、临床中心接触 | 备忘录、数据、意向 | 模型不可用 |
| 31–60 天 | 化学系列、体外级联、选择性 | SAR 表、先导系列 | 活性未达阈值 |
| 61–90 天 | 在体 PoC 方案、专利优先权、评审 | 方案、专利稿、材料 | 模型无法按期读出 |

## 七、底表
